# 诗词润童心 · 闯关互动页

完整题库来自附件 docx（非样稿），数据与页面分离。

## 题量自检

| 模块 | 数量 |
|------|------|
| 开篇 | 5（封面/赛程/难度/计分/过渡） |
| 九宫格 | 36（基础12 / 进阶12 / 拔高12） |
| 对句 | 36 |
| 填字 | 36 |
| 选择 | 36 |
| 图片 | 36（意境文案占位，三层揭晓） |
| 飞花令 | 36（参考默认折叠） |
| 收尾 | 4 |
| 另有卷间过渡页 | 若干 |

合计页面见 `js/bank.js` → `meta.counts`。

## 交互

- 每题先只显示问题；点「点击揭晓答案 / 对出下句 / 补全诗句」才显示答案。
- 选择题：点选项或揭晓按钮均可。
- 图片题：诗名 / 作者朝代 / 诗句 三层按钮分别揭晓。
- 飞花令：主题字展示，参考诗句默认折叠。
- 底栏上一页 / 下一页；顶栏快捷跳转卷/题型；「跳转卷/题型」可按题号跳。

## 视觉

浅米纸色 `RGB(245,240,230)`，角落淡墨梅枝装饰，标题楷体感、正文宋体感，移动端优先。

## 本地预览

```bash
cd poetry && python3 -m http.server 8791
# 打开 http://127.0.0.1:8791/
```

或在站点根目录起服务后访问 `/poetry/`。

## 部署

挂在 `everyday-english-site` 预览分支，路径 `/poetry/`，与 `/plum/` 并存；**不合 main**。

## 改题

编辑 `js/bank.json` 后重新生成 `bank.js`，或直接改 `bank.js` 中的 `window.POETRY_BANK`。
